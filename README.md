# 原石狂磨 (Magic Stone)

一个基于 Solidity 智能合约的链上游戏项目，核心玩法围绕 NFT 原石的收集、打磨升级和市场交易展开。玩家通过使用打磨工具提升原石品质，完成各类任务获取奖励，并在自由市场中买卖 NFT 资产。

**技术栈**: Solidity + Hardhat + React + TypeScript

---

## 矿石等级体系

```
原石(0级) ──打磨──→ 玛瑙(1级) ──打磨──→ 翡翠(2-x级) ──打磨──→ 钻石(3-x级) 🔒终点
```

每次打磨成功，矿石提升一个大等级，并随机获得该等级下的子等级。子等级仅影响收藏价值，不影响打磨成功率。

### 等级详情

| 编码 | 名称 | 颜色 | 描述 |
|------|------|------|------|
| 0级 | **原石** | 灰 | 未经打磨的原始矿石，一切奇迹的起点 |

| 2-1级 | **糯种翡翠** | 翠绿 | 质地温润如糯米汤，半透明，入门级翡翠 |
| 2-2级 | **冰种翡翠** | 翠绿 | 透明度高如冰块，清亮水头足 |
| 2-3级 | **玻璃种翡翠** | 翠绿 | 完全透明如玻璃，极为纯净 |
| 2-4级 | **帝王绿翡翠** | 翠绿 | 浓郁正阳绿，翡翠之王，拍卖级珍品 |
| 3-1级 | **普通钻石** | 冰蓝 | 标准无色钻石，璀璨夺目 |
| 3-2级 | **蓝钻** | 冰蓝 | 含硼元素呈蓝色，极度稀有 |
| 3-3级 | **粉钻** | 冰蓝 | 阿盖尔矿传奇，粉色钻石中的梦幻之选 |

### 子等级概率

升级到 2 级或 3 级时，子等级按以下概率随机分配：

| 子等级 | 概率 |
|--------|------|
| x-1 | 43% |
| x-2 | 30% |
| x-3 | 20% |
| x-4 | 7% |

### 打磨规则

- **0 级（原石）** 和 **1 级（玛瑙）** 无子等级
- **3 级（钻石）** 为最高等级，无法继续打磨
- 子等级不影响打磨成功率，成功率由大等级和工具等级决定
- 子等级不能在大等级内提升（如 2-1 不能磨成 2-2，只能磨到 3-x）
